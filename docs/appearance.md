# 外观与配色

浮窗右上角“更多”菜单 → **外观与配色**。

- 跟随系统、浅色、深色三种主题模式。
- 青瓷、海蓝、紫藤、暖砂四组强调色预设。
- 自定义强调色、窗口背景、卡片背景、主要文字和次要文字。可输入六位十六进制色值，或点击色块打开系统取色器。
- 点击“应用并保存”立即同步主浮窗和当前详情页。深浅主题各自保存；“恢复默认配色”只清除当前主题的覆盖值。
- 分隔线、悬停、按下、轨道和淡强调背景由基础颜色生成。错误与 Critical 保留独立语义色，避免自定义强调色改变告警含义。
- 非法色值不会写入设置。正文对比度偏低时提示调整，用户仍可保留自己的选择。

主浮窗按当前状态、性能指标、对话费用、诊断入口分区，宽度保持原规格。较小可用高度时可滚动；长标题截断并保留 tooltip。费用详情使用“此对话 / 账号额度”页签，共用 Astra / Fast 两项计价设置。详情窗口、菜单与按钮使用同一语义调色板。

实现：`DesignTokens.cs` 集中维护主题及派生颜色；`MainWindow.Appearance.cs` 管理配色交互；`MainWindow.Design.cs` 管理共享呈现。渲染验证覆盖主题切换、页签内容、设置往返、非法输入、恢复默认、预设、对比度和小屏滚动。
