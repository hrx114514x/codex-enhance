# 此对话费用估算

主浮窗“账号额度”下方显示当前选择对话的估算金额，点击进入“费用与额度”。页面顶部提供此对话金额、请求数、token 数、采样时间和用量明细。

- 默认每 10 秒后台刷新；关闭“自动刷新”保留上次结果，可单独手动刷新。设置重启后保留。切换到另一对话时读取一次该对话，迟到结果不会覆盖当前对话。
- 与账号额度共用“计入 Astra 长上下文加价”“计入已记录的 Fast 倍率”两个开关。关闭自动刷新时切换计价开关仍立即重算已经读取的用量。
- 统计此对话本机所有已发现日志，跨日期和额度周期；不含子任务、继承历史、语音及其他设备。来源日志只读，后台 worker 保存有界数量的对话数值账本，不依赖账号额度接口是否可用。
- 同一响应的物理副本及 token_count 镜像去重；无 response_id 的旧记录沿用周额度的签名规则。增量读取新日志，文件截断、替换、删除后重建。
- 这是模型用量的等效金额，非实际扣款或官方余额。使用现有价格表，缓存、长上下文和已记录 Fast 的换算与周额度一致。未记录速度按普通速度假设；缺价格、倍率或日志时标为“部分”，完全无可计价用量时不显示零美元。
- 只汇总已落盘的请求用量，不推测仍在生成中的 token。价格检查沿用既有更新机制；关闭自动刷新时价格变化留到下次手动刷新。

验证覆盖重复/镜像顺序、继承历史、跨文件追加、截断/删除、时间截止、缺价/损坏文件、10 秒调度、手动模式、切换及迟到结果；原生预览检查共用开关、刷新入口、设置恢复及深浅色布局。
